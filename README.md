# EMPU
 Essential Maths for Physics Undergrads is an open-source textbook, which covers important University level maths for physicists. No technical knowledge is assumed past the point of high-school science and mathematics. This book may serve as a pre-university text to future undergraduates or as a semi-technical source for curious readers.

*This project is under development. New versions of the book will be uploaded regularly. If you'd like to view the project, visit [the EMPU Overleaf page](https://www.overleaf.com/read/zftsdvjyyjvt#3ef1b8).*
